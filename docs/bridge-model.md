# 惠斯通电桥模型与桥臂编号约定

服务内部所有计算严格使用本节约定。HTTP 报文中的 `r1`/`r2`/`r3`/`r4`
即按下图编号，调用方不要自行换序。

## 电路图与编号

```
                      桥源 Vs（+ 在 A，− 在 C，C 为 0 V 参考）

                 A o──────────────────────────o
                    ╲                        ╱
                     ╲                      ╱
                    r1 ╲                  ╱ r2
                       ╲                ╱
                        ╲              ╱
              输出 B o───o────────────o───o D 输出
                          ╲        ╱
                           ╲      ╱
                          r4 ╲  ╱ r3
                              o
                              │
                 C o──────────┴───────────────o
                      桥源 Vs（−，0 V 参考）
```

* **A**：桥源正极；**C**：桥源负极（电位参考 0 V）。
* **r1**：臂 A → B
* **r4**：臂 B → C
* **r2**：臂 A → D
* **r3**：臂 D → C
* 输出端子为 **B、D**；规定输出电压 `V_out = V_B − V_D`。
* 检流计（内阻 Rg）接在 **B、D 之间**。

两条串联支路：

| 支路 | 串联臂 | 中点 |
|------|--------|------|
| 左支路 A→B→C | r1（上）、r4（下） | B |
| 右支路 A→D→C | r2（上）、r3（下） | D |

## 平衡条件（严格按相对臂乘积）

B、D 等电位（`V_out = 0`）当且仅当**两相对臂的乘积相等**：

```
r1 · r3 = r2 · r4
```

- r1 与 r3 相对，r2 与 r4 相对。
- **不是**「相邻臂相等」。相邻臂相等而相对臂乘积不等时，输出并不为零。
  该区别有专门的测试守护（`test_adjacent_arms_equal_is_not_balance`、
  `test_balance_condition_is_opposite_product_not_adjacent_equality`）。

## 不平衡时的开路输出

两条支路各是一个分压器，中点电位：

```
V_B = Vs · r4 / (r1 + r4)
V_D = Vs · r3 / (r2 + r3)

V_out = V_B − V_D
      = Vs · ( r4/(r1 + r4) − r3/(r2 + r3) )
```

输出对 Vs 是严格线性的：**桥源电压翻倍、同一失衡程度下 |V_out| 翻倍**。
固定其它三臂、单独增大一个桥臂时输出随之单调变化，并在越过平衡点时
**符号翻转**（由 B、D 谁电位高决定正负）。

## 接入检流计：戴维南等效

从输出端子 B、D 向桥内看，整桥等效为：

* 开路（戴维南）电压：`V_th = V_out`（即上面的开路分压差）
* 输出（戴维南）电阻：把理想桥源短路后，A、C 等电位，于是
  `R_th = (r1 ∥ r4) + (r2 ∥ r3)`

检流计内阻为 Rg 时：

```
Ig = V_th / (R_th + Rg)          # 正方向 B → D，即偏转量
Vg = Ig · Rg = V_th · Rg / (R_th + Rg)
```

Rg → ∞ 时 Vg → V_th，回到开路情形；平衡时 V_th = 0，Ig = 0。
实现见 `app/thevenin.py`，不允许用「差了几个欧姆」之类的口头估计替代。

## 反推待测臂（平衡的闭式解）

由 `r1·r3 = r2·r4` 解出任一未知臂：

| 未知臂 | 闭式解 |
|--------|--------|
| r1 | `r1 = r2 · r4 / r3` |
| r2 | `r2 = r1 · r3 / r4` |
| r3 | `r3 = r2 · r4 / r1` |
| r4 | `r4 = r1 · r3 / r2` |

解出的臂代回正算接口，开路输出必须归零（正算/反解自洽闭合）。
此闭合关系对四个未知臂位置分别有参数化测试守护
（`test_solve_then_forward_is_a_zero_output_closure`）。

## 基准算例

四臂相等（如 r1=r2=r3=r4=100 Ω）时，两个中点都在 Vs/2，
对任意 Vs 都有 `V_out = 0`。该可手算基准已钉入回归测试：
`test_equal_arm_baseline_output_is_exactly_zero`、
`test_equal_arm_baseline_zero_output_is_pinned`。

## 零桥源电压的约定

`Vs = 0` 是合法工况，**不是错误**：由分压关系输出恒为零，接口直接返回
零输出并在 `note` 中明确标注；接检流计时电流、端电压同样为零。
